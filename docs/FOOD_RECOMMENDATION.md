# 지금 뭐 먹지? — StartupOS 음식 추천 데모

음식 종류, 예상 예산, 소요 시간, 매운맛 제외 및 채소 중심 조건을 선택하면 정해진 메뉴 목록에서 조건에 맞는 메뉴를 추천한다. 조건에 맞는 메뉴가 없으면 조건을 바꾸도록 안내하며, 이전 추천을 브라우저에 저장해 선택지가 여러 개일 때 다른 메뉴를 우선 추천한다. 메뉴 가격과 시간은 예시이며 매장별 정보, 실제 영양 성분, 알레르기 안전성 또는 채식 인증을 보장하지 않는다. 위치, 식당 검색, 배달, 결제, AI 호출은 제공하지 않는다.

StartupOS는 음식 추천 관련 기획 문구를 `food` 범위로 인식한다. `food`는 기존 Build API에서 범위 승인 후 조립하고, 음식 브라우저 시나리오 증거를 포함한 검증이 통과해야 배포할 수 있다. 최근 추천만 해당 앱의 브라우저 저장소에 보관한다.

로컬 검증: `npm run test:browser` (브라우저 증거 갱신), `npm test`. 이 기능은 API와 웹 UI 모두의 변경을 필요로 한다. 현재 전체 공통 소스 해시를 검증하는 기존 설계상, 운영 API에 이 변경을 배포하면 기존 산출물의 재빌드가 필요하거나 기존 앱 제공에 영향을 줄 수 있다. 운영 반영 전에 기존 앱의 호환성과 API·작업 워커·UI 동시 배포 계획을 검증해야 한다. UI 전용 배포만으로는 이 기능을 사용할 수 없다.

## 근처 식당 검색 시제품

사용자가 위치 검색을 선택하면 브라우저 위치 동의를 받은 뒤 좌표를 OpenStreetMap Overpass 서비스로 전송해 주변 식당을 조회한다. 선호 음식과 예산은 이 브라우저에 저장한다. 결과는 직선거리와 명시적으로 제공된 데이터에 근거해 순위를 정한다. 음식 종류, 리뷰, 영업 상태, 가격과 대기 정보가 없으면 확인 필요로 표시한다. 대기시간이나 화제성은 계산하지 않고, 메뉴 가격·알레르기 안전성을 추정하지 않는다. OpenStreetMap 자료는 등록 범위와 최신성이 보장되지 않고, 좌표가 있는 처음 50개 식당만 처리하므로 가장 가까운 식당 전체를 빠짐없이 찾는 기능은 아니다. 검색 데이터는 식당 지도 링크로 출처를 표시한다. 무료 공용 검색 서버는 서비스 가용성이나 SLA를 보장하지 않으며 사용자 과금이 없는 운영용 검색 인프라로 간주할 수 없다.

자동 브라우저 테스트는 위치와 검색 응답을 모의한다. 2026-10-28 로컬 환경에서 실제 Overpass 서버는 HTTP 406으로 요청을 거절했다. 실제 근처 식당 검색은 아직 확인되지 않았고, 리뷰·실제 메뉴와 가격·인기 추이·실시간 대기시간은 이 데이터 소스에서 제공되지 않는다. 이를 구현하려면 해당 정보를 합법적으로 제공하는 사업자와 인증·사용 조건 및 운영 비용을 정해야 한다. 위치 검색에는 외부 전송 고지와 사용자 동의가 필요하다. 서버 호출 제한은 인스턴스별 임시 제한이며 전역 한도가 아니다.
